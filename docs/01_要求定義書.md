## 1. 背景

セキュアカメラの貸出は、現在、紙の帳票への記入と管理者による帳票チェックで運用している。この運用が利用者・管理者双方の負担になっており、貸出フローの改善が求められている。

## 2. 現状フロー（As-Is）

1. 借りたい人が帳票に記入する
2. 借りたい人が管理者に帳票チェックを依頼する
3. 棚を開けてカメラを取り出し、使い終わったら返す

詳細は [03_業務フロー定義](03_業務フロー定義.md) を参照。

## 3. 課題

| 課題ID | 課題 | 影響 |
|--------|------|------|
| ISS-1 | 帳票を書くこと自体が面倒 | 記入漏れ・記入の形骸化 |
| ISS-2 | 管理者が不在だと借りられない | 業務が止まる |
| ISS-3 | 管理者を探す手間がかかる | 貸出がスムーズでない |

## 4. 目的・ゴール

セキュアカメラ貸出を、紙の帳票と管理者チェックから「**社員証タッチで鍵を借りる**」方式へ置き換え、以下を達成する。

| ゴールID | ゴール | 対応課題 |
|----------|--------|----------|
| GOAL-1 | 管理者の立ち会いなしで貸出・返却を完結できる | ISS-2, ISS-3 |
| GOAL-2 | 記入の手間をなくし、記録を自動化・確実化する | ISS-1 |
| GOAL-3 | 誰がいつ借りて返したかを、帳票と同等以上に確実に残す | ISS-1 |

## 5. ビジネス要求

| 要求ID | 要求 | 背景・狙い | 対応ゴール |
|--------|------|-----------|-----------|
| BR-1 | 社員証をかざすだけで本人を識別したい | 記入の手間と本人確認の省力化 | GOAL-1, GOAL-2 |
| BR-2 | 登録された人だけが借りられるようにしたい | セキュア機材の持ち出し統制 | GOAL-1 |
| BR-3 | 管理者が不在でも貸出・返却できるようにしたい | 業務停止の解消 | GOAL-1 |
| BR-4 | 貸出時間を選んで借りられるようにしたい | 返却予定の見える化、延滞把握の前提 | GOAL-3 |
| BR-5 | 誰がいつ借りていつ返したかを自動で記録したい | 帳票の置き換え、追跡性の確保 | GOAL-3 |
| BR-6 | 記録を帳票と同じ形式で出力したい | 既存運用・監査への移行コスト低減 | GOAL-3 |
| BR-7 | 次に借りたい人が貸出状況を把握できるようにしたい | 鍵が1本のため待ち判断を助ける | GOAL-1 |
| BR-8 | 将来、複数の物品にも広げられるようにしたい | 他機材への横展開ニーズ | — |

## 6. 対象ユーザー（ステークホルダー）

| ロール | 説明 | 主な関心事 |
|--------|------|-----------|
| 利用者 | カメラを借りる社員 | 早く・簡単に借りて返したい |
| 管理者 | メンバー登録とログ管理を行う社員 | 統制と記録を保ちつつ立ち会いから解放されたい |
| 依頼者 | 本件の発注者 | 課題が解決し、現場で回ること |

## 7. スコープ

### 7.1 スコープに含む（フェーズ1）

- 社員証（IDm）による認証と、登録メンバーのみの利用制限
- 貸出（時間選択・解錠・ログ記録）
- 返却（本人確認・解錠・返却日時記録）
- 貸出状況の表示
- メンバー登録・削除（管理者）
- 貸借ログの CSV 出力（管理者）
- 保管庫の解錠制御（数秒通電）
- 延滞の画面表示

### 7.2 スコープに含まない（フェーズ2以降 / 対象外）

| 区分 | 項目 | 理由 |
|------|------|------|
| フェーズ2 | 延滞通知（メール・チャット） | まず画面表示で運用し、必要性を見てから |
| フェーズ2 | 複数物品対応 | データ設計のみ先行、機能実装は後 |
| フェーズ2 | Webブラウザからのログ閲覧 | 現場端末での出力を優先 |
| 対象外 | 施錠の自動化 | 施錠は人の手で行う（D8） |
| 対象外 | カメラ本体の管理・資産管理 | 貸出フローの改善が目的 |
| 対象外 | 社員証内部データの読み取り | IDm のみで識別（P4） |

## 8. 前提・制約

| ID | 前提・制約 | 出典 |
|----|-----------|------|
| PRE-1 | 管理者チェックは省略してよい（管理者了解済み） | D5 |
| PRE-2 | 鍵は1本で、使用のたびに保管庫へ戻す | D7 |
| PRE-3 | 返却後の施錠は人が行い、システムは解錠のみ担当 | D8 |
| PRE-4 | 対象物品は現時点でセキュアカメラのみ | D9 |
| PRE-5 | ハードウェアは Raspberry Pi + タッチスクリーン + RC-S380 + LE-53 + 駆動回路 | D10 |
| PRE-6 | 社員証は FeliCa とみられるが、要実機確認 | 確認事項 |

## 9. 成功基準

| ID | 成功基準 |
|----|----------|
| SC-1 | 利用者が管理者の立ち会いなしに、社員証タッチから貸出・返却まで完結できる |
| SC-2 | 未登録の社員証では貸出できない |
| SC-3 | すべての貸出・返却が貸借ログに記録され、CSV で出力できる |
| SC-4 | 現場のタッチ操作だけで、貸出は数タッチ以内で完了する |
