# 用語集

本プロジェクトで使用する用語を定義します。ドキュメント間で表記と意味を統一するための基準です。

| 用語 | 読み / 別名 | 定義 |
|------|------------|------|
| セキュアカメラ | — | 貸出対象のカメラ。社内で管理が必要な機材。本システムの唯一の貸出物品（フェーズ1）。 |
| 社員証 | ICカード | 利用者が所持する FeliCa 系とみられる非接触ICカード。本システムでは IDm で個人を識別する。 |
| IDm | アイディーエム | FeliCa カードの製造時固有ID（Manufacture ID）。カードごとに一意で、本システムの認証キーとして用いる。 |
| カードリーダー | リーダー / RC-S380 | 社員証をかざして IDm を読み取る非接触ICカードリーダー（Sony PaSoRi RC-S380 想定）。 |
| 保管庫 | 鍵ボックス | カメラ棚の鍵を収める箱。電磁ソレノイドロックで施錠され、システムが解錠する。 |
| 鍵 | — | カメラを収めた棚を開けるための物理鍵。保管庫に1本のみ格納。使用のたびに保管庫へ戻す運用。 |
| 電磁ソレノイドロック | ソレノイドロック / LE-53 | 通電により可動するソレノイド錠（LE-53 想定）。保管庫の施解錠に用いる。 |
| ロック駆動回路 | ドライブ回路 | GPIO の弱い信号でソレノイドの大電流を on/off する回路（リレーまたは MOSFET + 還流ダイオード）。 |
| 解錠 | アンロック | 保管庫を開けられる状態にすること。システムはソレノイドへ数秒通電する「解錠のみ」を担当する。 |
| 施錠 | ロック | 保管庫を閉じて固定すること。本システムでは**人の手**で行う（システムは関与しない）。 |
| 貸出 | 借用 | 利用者が鍵を保管庫から取り出すこと。貸出ログの登録と解錠を伴う。 |
| 返却 | — | 利用者が鍵を保管庫へ戻すこと。返却日時の記録と解錠を伴う。 |
| 貸借ログ | 貸出ログ / LOAN | 誰がいつ借り、いつ返したかの記録。紙帳票1行に相当する。CSV出力の元データ。 |
| 貸出中 | — | 鍵が持ち出されている状態。LOAN の `returned_at` が NULL の行が存在する状態。 |
| 延滞 | — | 返却予定時刻（`due_at`）を過ぎても未返却の状態。 |
| 返却予定時刻 | due | 貸出日時に貸出時間（duration）を加えた、返却が見込まれる時刻。 |
| メンバー | 登録メンバー / MEMBER | 本システムの利用を許可された人。社員証 IDm と氏名・社員番号がひも付く。 |
| 利用者 | ユーザー | メンバーのうち、貸出・返却・状況確認を行う人。 |
| 管理者 | アドミン / admin | メンバー登録・ログ出力の権限を持つ人。利用者としての貸出・返却も行える。 |
| 待機画面 | ホーム / S01 | 操作がないときに表示する初期画面。物品の状態を表示し、社員証タッチを待つ。 |
| NTP | — | Network Time Protocol。ネットワーク経由で時刻を同期する仕組み。 |
| RTC | リアルタイムクロック | 電池でバックアップされた時計モジュール。ネットワークがない場合の時刻保持に用いる。 |
| nfcpy | — | Python の NFC/FeliCa 制御ライブラリ。RC-S380 から IDm を読む用途に使用予定。 |
| GPIO | ジーピーアイオー | Raspberry Pi の汎用入出力ピン。解錠信号の出力に用いる。 |
| スタンドアロン | — | 単体で完結する構成。本システムは Raspberry Pi 1台で動作し、常時のサーバ接続を前提としない。 |
