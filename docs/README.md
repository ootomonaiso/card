## ドキュメント間のトレーサビリティ

```
要求（01）
  └─ 要件（02 FR/NFR）
       ├─ ユースケース（04 UC）
       ├─ 業務フロー（03）
       ├─ 画面（07 S/A）
       ├─ 動的設計（08）
       ├─ DB（06）
       └─ ハードウェア（09）
未決事項は 10 課題・確認事項管理表 に集約し、各ドキュメントから参照する。
```

## 図の表記について

図はすべて [Mermaid](https://mermaid.js.org/) 記法で記述しています。VS Code（Markdown Preview Mermaid Support 等）、GitHub、Obsidian でそのままプレビューできます。

## フェーズ方針

- **フェーズ1：** 帳票と管理者チェックの置き換え（認証・貸出・返却・ログ・メンバー管理）
- **フェーズ2：** 複数物品対応・延滞通知・Webログ閲覧

フェーズ1の最終スコープは [10_課題・確認事項管理表](10_課題・確認事項管理表.md) の回答確定後に確定します。
